Shared memory contention

One CPU and memory configuration; competing device traffic varies across workloads.

Synthetic device traffic enters Ramulator directly, bypassing CPU caches. It shares the controller with the guest and uses a disjoint address window. GPU-like access patterns model DRAM contention only; GPU compute, page migration and coherence are not simulated. Achieved GB/s uses accepted bytes per simulated ROI second. Read latency covers all guest DRAM clients. Command gaps measure host receipts in simulated time, with gaps above 1.5 control periods flagged; they are not controller execution times. Host scan age describes the host's latest scan, not the scan used by the controller.
