Interpretation

Each measurement window is 2 s: 194 publications per control direction or 60 frames per camera. This is a sustained-window check, with limited evidence for rare tails. The stereo latest case preserves application sensor queues and permits replacement. Stereo lossless uses reliable depth 128 for all five measured streams and disables replacement and expiry.

Native timestamps have 1 ms clock buckets. The gap to native includes modeled guest CPU and memory costs. Full-byte image validation and DMA guard/reset tests are separate from these performance runs. The DMA model includes coherent memory timing and IRQ handling; a separate PCI link-rate limit is not modeled.
