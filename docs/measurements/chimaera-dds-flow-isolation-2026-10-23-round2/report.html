Interpretation

Each timing window has a 0.2 s source period: about 50 joint/effort and 200 clock receipts. Joint/effort p99 therefore equals the observed maximum. Repetitions describe variability; these tests do not establish sustainable throughput or a tail guarantee.

Creation-start latency begins before logical per-sample preparation of a reused payload. Initial allocation and physical sensor capture are excluded. Publish-entry latency starts at publication; scheduled-release age also includes source scheduling delay. These are distinct boundaries. Host computation while gem5 is paused has zero simulation-time cost in both modes, and host timestamps use the coupling clock.

The callback marker follows a lifecycle guard. Trace recording and locking add guest work; observer overhead has not been isolated.
