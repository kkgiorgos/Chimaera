Choose a pipeline stage

Passive evaluation branches from physics into result.json and ground_truth.csv, then into this offline replay. Evaluation does not feed the controller. Simulation timestamps measure observation age, cadence, flight, and braking schedules. Computation durations use the native steady wall clock; they are not gem5 instruction timings or an end-to-end latency trace.

Flight and reaction windows use simulation time. Processing uses native wall time. These measurements describe this run; they do not establish a guaranteed deadline or catch probability.
